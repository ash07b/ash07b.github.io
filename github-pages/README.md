# ash07b.github.io

Personal portfolio for Aishwarya B.

## Publish on GitHub Pages
1. Create a public repo named exactly `ash07b.github.io`.
2. Upload everything in this folder (`index.html`, `styles.css`, `script.js`, `assets/`, `.nojekyll`).
3. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. The site goes live at https://ash07b.github.io within a minute or two.

To update after a new resume: edit the text in `index.html` and push.
